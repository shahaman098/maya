Write like you,
faster.

Maya learns how you write from your own messages and emails, then rewrites drafts in your voice. Your writing stays on your computer.

Download for Windows

Windows 10 or 11 · 64-bit · free

  1. Step 1Open Maya-Setup.exe

    It installs in one click and opens Maya. You won't need an admin password.

  2. Step 2Pick local or API key

    Click Install everything to run the AI on your PC, or paste an API key.

  3. Step 3Add your writing

    Paste 10–20 things you've written, then rewrite your first draft.

If Windows says "Windows protected your PC", click More info → Run anyway. This happens because the installer isn't code-signed yet.
